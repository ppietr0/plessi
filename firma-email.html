Come installarla

Scegli il tuo Outlook. Bastano 2 minuti.

Outlook (app desktop Windows)

  1. Clicca Copia firma qui sopra.
  2. In Outlook: File → Opzioni → Posta → Firme…
  3. Premi Nuova, dai un nome (es. "Plessi").
  4. Clicca nel riquadro grande e incolla (Ctrl+V).
  5. Imposta la firma come predefinita per nuovi messaggi e risposte, poi OK.

Outlook sul web / Microsoft 365

  1. Clicca Copia firma qui sopra.
  2. Apri Impostazioni (⚙) → Posta → Composizione e risposta.
  3. Nel riquadro firma incolla (Ctrl/Cmd+V).
  4. Scegli di usarla per nuovi messaggi e risposte.
  5. Salva.
Mac (nuovo Outlook / Apple Mail): incollare l'HTML a volte non basta. In quel caso usa Copia codice HTML, salva il testo in un file firma.html, aprilo nel browser, seleziona tutto (Cmd+A), copia e incolla nel riquadro firma. È il metodo più affidabile su Mac.
